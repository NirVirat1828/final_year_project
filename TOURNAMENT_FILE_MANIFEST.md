## 🎨 Visualization Files (Generated by Tournament)

### 9. tournament_figures/
**Purpose:** Directory containing all generated visualizations  
**Files Created:**

#### pca_scatter_comparison.png
- 2D PCA projection
- Side-by-side: Raw vs Processed data
- Color-coded by freshness grade
- Shows class separation

#### confusion_matrix_*.png
- Heatmap format
- Shows classification accuracy per grade
- Color intensity = prediction count
- Diagonal = correct predictions

#### signal_comparison.png
- Line plot overlay
- Raw signal vs Savitzky-Golay smoothed
- Demonstrates preprocessing effect

#### parity_plot_*.png
- Scatter plot: Predicted vs Actual days
- Red y=x reference line
- Metrics annotation (RMSE, R²)
- Regression quality visualization

#### classification_performance.png
- Bar charts comparing all classifiers
- Grouped by preprocessing method
- Two panels: Accuracy & F1-Score

#### regression_performance.png
- Bar charts comparing all regressors
- Grouped by preprocessing method
- Two panels: RMSE & R²
